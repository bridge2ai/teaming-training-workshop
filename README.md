## Teaming training

[![Quarto Publish](https://github.com/bridge2ai/teaming-training-workshop/actions/workflows/publish.yml/badge.svg)](https://github.com/bridge2ai/teaming-training-workshop/actions/workflows/publish.yml)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Open materials for the **Bridge2AI Team Science Training Workshop**, a half-day, six-module workshop developed by the Bridge2AI Teaming and Collaboration Working Group. It helps interdisciplinary research teams build social infrastructure through hands-on teaming artifacts and the "Monday Morning Protocol." The rendered site is at <https://bridge2ai.github.io/teaming-training-workshop>.


### Development

To convert markdown to publication format, first [download and install quarto](https://quarto.org/docs/get-started/).

Then, from the command line:

```bash
quarto render 
```

Or for interactive development

```bash
quarto preview
```

### Automation

The site will automatically build and deploy using github actions.
